朱自清《春》考霸背诵与赏析卡

这页不再只是“能背下来”，而是按高分思路重排成三层：先抓结构链，再抓每段题眼，最后直接过渡到赏析表达。 目标很明确：背诵不散、默写不漏、答题不空。

全文口诀 背下这七个字 = 拿下全文结构
盼盼春 醒春醒 草春草 树春花 风春风 雨春雨 人迎春

口诀就是全文地图：答题先念「盼醒草树风雨人」定位段落。标红的「树·风·雨」最容易考赏析； 结尾三喻（娃娃→姑娘→青年）是收束，见 08 颂春卡。

朱自清
1898 - 1948 · 散文家 / 诗人 / 学者

《春》是教材里的经典写景散文。它厉害的地方，不只是景物写得美，而是把“春天来了”拆成草、花、风、雨、人，再一路推到希望和生命力。

高频命题点：修辞赏析、写景顺序、情感主旨、结构作用、词句表达效果。
全文口诀
7 个字
最容易出题
花 / 风 / 雨
结尾重点
3 个比喻
答题抓手
手法 + 作用 + 情感

考霸视角：先背什么，答题怎么说

先拿住结构，再记住每段核心画面，最后把赏析句式练顺。

口诀：盼 醒 草 树 风 雨 人 借景抒情 由景到人

1. 主旨一句话

文章通过描绘春草、春花、春风、春雨和迎春图，赞美春天的生机、美好与希望。

2. 结构一句话

开头盼春，中间绘春，后面迎春，结尾颂春，层层推进，气势越来越足。

3. 赏析一句话

先点修辞或感官描写，再说写出了什么景，再落到“表达了对春天的喜爱赞美”。

4. 晨读顺序

先通读全文，再背结构链，最后重点盯住春花、春风、春雨和结尾三喻。

看春花 看春风 看春雨 看结尾三喻
盼春

开篇先把情绪拉满，先有盼头，后有春景。

盼01
考点：反复手法，突出盼春心切，为下文总领全文蓄势。
速记提示盼啊盼，东风到，春天一步步走近。
原文盼望着，盼望着，东风来了，春天的脚步近了。
高分表达连用两个“盼望着”，运用反复，直接写出作者急切期待春天到来的心情，开篇点题，也为下文绘春蓄足情感力量。
总写春醒

不是一上来就写具体景物，而是先让整个世界“醒过来”。

醒02
考点：总领下文，拟人化总写，给全文定下“欣欣向荣”的底色。
速记提示大地睁眼，山润、水涨、太阳脸红。
原文一切都像刚睡醒的样子，欣欣然张开了眼。山朗润起来了，水涨起来了，太阳的脸红起来了。
高分表达作者先从整体上写春天苏醒，运用拟人的写法，把山、水、太阳写得有神有情，既总写春景，也自然引出后面的分写。
春草图

从最容易被忽略的小草写起，春天的生命力一下就立住了。

草03
考点：“偷偷地”“钻”最常考；写草也写人，景中有人的活动感。
速记提示小草偷偷钻出土，嫩嫩绿绿一大片，人在草上玩，风轻草软。
原文小草偷偷地从土里钻出来，嫩嫩的，绿绿的。园子里，田野里，瞧去，一大片一大片满是的。坐着，躺着，打两个滚，踢几脚球，赛几趟跑，捉几回迷藏。风轻悄悄的，草软绵绵的。
高分表达“偷偷地”和“钻”把小草写活了，既写出不经意间萌发的动态，也写出旺盛的生命力；后面连写人的活动，让春草不只是“看得到”，还让人“想扑进去”，画面特别有参与感。
春花图

这段最容易拿高分，因为颜色、气味、联想、动物都写进去了。

树04
考点：比喻、拟人、虚实结合、多感官描写，是赏析重灾区。
速记提示桃杏梨争开花，红像火、粉像霞、白像雪；香甜、蜂闹蝶飞、野花像眼睛星星。
原文桃树、杏树、梨树，你不让我，我不让你，都开满了花赶趟儿。红的像火，粉的像霞，白的像雪。花里带着甜味儿；闭了眼，树上仿佛已经满是桃儿、杏儿、梨儿。花下成千成百的蜜蜂嗡嗡地闹着，大小的蝴蝶飞来飞去。野花遍地是：杂样儿，有名字的，没名字的，散在草丛里，像眼睛，像星星，还眨呀眨的。
高分表达这一段从颜色、气味、联想和动态几个角度写春花。先用拟人写花“赶趟儿”，再用三个比喻把色彩写得鲜明热烈；“闭了眼”一句由实到虚，写出花开之盛已经让人联想到果实满枝；蜂蝶和野花的加入，又让画面更热闹、更灵动。
春风图

这段最妙的地方，是把“看不见”的风写成“摸得到”“闻得到”“听得到”。

风05
考点：多感官描写很典型，触觉、嗅觉、听觉一齐上场。
速记提示春风像母亲的手；泥土味、青草味、花香；鸟唱歌，牧童吹笛。
原文“吹面不寒杨柳风”，不错的，像母亲的手抚摸着你。风里带来些新翻的泥土的气息，混着青草味儿，还有各种花的香，都在微微润湿的空气里酝酿。鸟儿将窠巢安在繁花嫩叶当中，高兴起来了，呼朋引伴地卖弄清脆的喉咙，唱出宛转的曲子，与轻风流水应和着。牛背上牧童的短笛，这时候也成天在嘹亮地响。
高分表达作者先用“像母亲的手抚摸着你”写春风的温柔，这是触觉；再写泥土、青草和花香，这是嗅觉；最后写鸟鸣和笛声，这是听觉。看不见的春风，因为多感官描写，变得又真又暖，特别有感染力。
春雨图

这段有细密的雨，也有傍晚的人间烟火，最能写出春的温润和平。

雨06
考点：三个比喻“牛毛、花针、细丝”常考，后半段环境气氛也常考。
速记提示春雨最寻常，像牛毛、花针、细丝；灯光黄晕，人慢慢走，农夫披蓑戴笠，草屋静默。
原文雨是最寻常的，一下就是三两天。可别恼。看，像牛毛，像花针，像细丝，密密地斜织着，人家屋顶上全笼着一层薄烟。树叶子却绿得发亮，小草也青得逼你的眼。傍晚时候，上灯了，一点点黄晕的光，烘托出一片安静而和平的夜。乡下去，小路上，石桥边，有撑起伞慢慢走着的人；还有地里工作的农夫，披着蓑，戴着笠的。他们的草屋，稀稀疏疏的，在雨里静默着。
高分表达三个比喻连用，写出春雨细、密、亮的特点；“斜织着”又让雨有了动态。后面从植物写到灯光、行人、农夫和草屋，画面从自然推进到人间生活，烘托出春夜安静、温润、和平的氛围。
迎春图

写到这里，春天不只是景，更变成了人的行动和希望。

07
考点：由写景转向写人，点出“一年之计在于春”，揭示春天的意义。
速记提示风筝多了，孩子多了，家家户户都出来了，舒筋骨、抖精神，一年之计在于春。
原文天上风筝渐渐多了，地上孩子也多了。城里乡下，家家户户，老老小小，他们也赶趟儿似的，一个个都出来了。舒活舒活筋骨，抖擞抖擞精神，各做各的一份事去。“一年之计在于春”，刚起头儿，有的是工夫，有的是希望。
高分表达作者由前面的写景转入写人，写出春天带来的活力和希望。这里的春不只是自然季节，更是一种新的开始，所以文章的感情也从“喜爱春景”推进到“赞美生活与希望”。
结尾三喻颂春

娃娃、小姑娘、青年，三个比喻一层比一层有力量，必须单独记牢。

颂08
考点：三个比喻的顺序和作用很关键，分别对应新、生、美、健。
速记提示新生的娃娃 → 花枝招展的小姑娘 → 健壮的青年，最后“领着我们上前去”。
原文春天像刚落地的娃娃，从头到脚都是新的，他生长着。
春天像小姑娘，花枝招展的，笑着，走着。
春天像健壮的青年，有铁一般的胳膊和腰脚，他领着我们上前去。
高分表达结尾连用三个比喻，把春天写成娃娃、小姑娘和青年，层层递进。先写“新”，再写“美”，最后写“健”，不仅照应全文，也把作者对春天的赞美推向高潮，让文章在昂扬有力中收束。

最后冲刺提醒

  • 不要只死背句子，要先背“盼醒草树风雨人”的顺序。
  • 春花、春风、春雨是最容易考赏析的三段。
  • 结尾三喻常考顺序和表达效果，单独背三遍。

默写自检清单

  • “偷偷地”“钻出来”“赶趟儿”“酝酿”这些词别写错。
  • “红的像火，粉的像霞，白的像雪”顺序别乱。
  • “牛毛、花针、细丝”“娃娃、小姑娘、青年”必须完整。
